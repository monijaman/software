## The 7-second test

A recruiter often scans a resume for a few seconds before deciding to read on. In that time they look for: **job title, recent company, key skills, and one impressive result**. Put those where the eye lands first.

## What an ATS is

Most companies receive resumes through an **Applicant Tracking System** (Greenhouse, Lever, Workday and others). It turns your file into text and lets recruiters filter by keywords. If the text comes out broken, a human may never see you.

| ✅ Do | ❌ Avoid |
| --- | --- |
| Simple one-column layout | Two columns, text boxes, tables for layout |
| Standard headings: *Experience, Skills, Education, Projects* | Creative headings like "My Journey" |
| Export to PDF from Google Docs / Word | Scanned images or Canva designs with text as pictures |
| Use the job post's exact words (e.g. "PostgreSQL", "CI/CD") | Skill bars and star ratings |

## Recommended structure

1. **Header**: name, city, email, phone, LinkedIn, GitHub / portfolio.
2. **Summary** (2–3 lines): who you are + years + stack + one strength.
3. **Skills**: grouped (Languages, Frameworks, Databases, Cloud/DevOps).
4. **Experience**: newest first, 3–5 bullets each.
5. **Projects**: 2–3, with link and tech used. Most important if you have little experience.
6. **Education & Certifications**.

## Write bullets with impact

Use the formula **Action verb + what you did + measurable result**.

❌ *Responsible for backend APIs.*

✅ *Built 14 REST endpoints in NestJS for the order service, cutting checkout errors by 32% and p95 latency from 900 ms to 220 ms.*

No numbers? Use scale (users, requests, records), time saved, or money saved. Estimates are fine if you can explain them.

## Tailor for each application

Keep a **master resume** with everything. For each job, copy it and:

1. Reorder skills to match the post.
2. Move the most relevant project up.
3. Use the same job title wording if it is honest.

## Cover letter (short)

Three short paragraphs: why this company, the one result that proves you fit, and a clear next step. Mention something specific about the company so it cannot be sent anywhere else.

## Final checklist

- [ ] 1 page (under 5 years experience) or 2 pages max
- [ ] Every bullet starts with a verb, most have a number
- [ ] No spelling mistakes (read it aloud)
- [ ] File named `Firstname-Lastname-Backend-Engineer.pdf`
- [ ] Links work and GitHub has pinned, readable repos
