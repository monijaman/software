## Do certifications matter?

A certificate alone rarely gets you hired. It **does** help in three cases:

- Your resume lacks professional experience in that area.
- The job post lists it (common for cloud, DevOps and consulting companies).
- Your company is a partner of AWS, Microsoft or Google and needs certified staff.

Pair every certificate with a project that uses the same skills.

## Cloud

| Certification | Level | Good for |
| --- | --- | --- |
| AWS Certified Cloud Practitioner | Entry | First cloud certificate, non-specialists |
| **AWS Certified Developer – Associate** | Associate | Backend developers on AWS |
| **AWS Certified Solutions Architect – Associate** | Associate | Most requested AWS certificate |
| AWS Solutions Architect – Professional | Advanced | Senior / architect roles |
| Microsoft Azure Fundamentals (AZ-900) | Entry | Azure-based companies |
| Azure Developer Associate (AZ-204) | Associate | .NET and Azure developers |
| Google Cloud Associate Cloud Engineer | Associate | GCP-based companies |

## How to choose

1. Look at 10 target job posts. Which certificate appears most?
2. Start with an **associate** level, not a fundamentals one, if you already code.
3. Book the exam date first (4–8 weeks away). A deadline keeps you going.
4. Use official practice exams, then build one project with the same services.

> 💡 Exam names and versions change. Always check the vendor's official page for the current exam code, price and validity before you study.
